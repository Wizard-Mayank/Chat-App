# 🟢 Chat_App

> A WhatsApp-inspired web app built with **React + Vite**  
> Familiar UI.  
> Clean code.  
> Zero Meta involvement 😄

---

## 🤔 What is this?

**Chat_App** is a minimal WhatsApp-style chat interface built to understand how modern messaging apps are structured on the frontend.

No ads.  
No spam forwards.  

Just UI, logic, and peace. 😌

---

## 🧠 Tech Stack

Simple tools. Solid choices.

- ⚛️ **React** — component-based UI, no chaos  
- ⚡ **Vite** — fast builds because life is short  
- 🟨 **JavaScript (ES6+)** — flexible, powerful, sometimes annoying  
- 🎨 **CSS** — simple styling, no unnecessary drama  
- 🧹 **ESLint** — politely tells me when my code is nonsense  

> Backend not included (yet).  
> Frontend doing frontend things — properly. 🧑‍💻

---

## ✨ Features

✔️ WhatsApp-style layout  
✔️ Chat screen UI  
✔️ Minimal & distraction-free design  
✔️ Easy to extend with a backend

❌ No real messages  
❌ No blue ticks (mental health first 🧘‍♂️)

## 🛠️ Run Locally

Because good apps deserve to be run, not just stared at 👇

```bash
git clone https://github.com/Wizard-Mayank/Chat-App.git
cd Chat-App
npm install
npm run dev
```

---

Open `http://localhost:5173` and enjoy pretending you built Chat App 😄
